Basics

  • Single Player: starts Morrowind in your browser.
  • Multiplayer: opens the server browser so you can host or join a game.
  • Tools: controls render quality, fullscreen, touch controls, saves, and mods.
  • Account: sign in for cloud saves and chat access.
  • Chat: opens the site chat rooms.
  • Saves: browser saves stay on this device unless you upload, import, or export them.

Mobile

  • Use the left stick to move and the right pad to look.
  • Open Tools if touch controls or render quality need adjustment.

Tech

Morrowind runs here through open-source engine and browser runtime work. The original game data is still required.

  • OpenMW - open-source Morrowind engine.
  • TES3MP - multiplayer built on OpenMW.
  • Emscripten - compiles native code to WebAssembly.
  • WebRTC - browser peer connection technology.
